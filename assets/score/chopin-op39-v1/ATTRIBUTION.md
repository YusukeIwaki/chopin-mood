The original **kern files 039-1-TR.krn (Troupenas, primary) and
039-1-BH.krn (Breitkopf & Härtel, corroborating) are unchanged copies from
commit 95dfb105c1669c72d10b04088566154f12d3dc1c of that repository.
The compact note JSON files are adaptations generated locally by
`scripts/build_score_reference.py`: rational score time, duration, MIDI pitch,
staff, bar, beat, attack flag and original source line. The musical work is
Chopin, Scherzo No. 3 in C-sharp minor, Op. 39. This reference contains no
performance recording.
