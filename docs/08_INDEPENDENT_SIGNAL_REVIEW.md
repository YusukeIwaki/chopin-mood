# 親エージェントによる独立信号レビュー

2026-10-19。ユーザーの指示を受け、解析・仮説の採否を親エージェントが担当し、museには範囲と受け入れ条件を限定した実装を渡す方式へ移行した。以下は初回P0を対象にした独立測定であり、後続修正後の映像の測定値とは区別する。

再実行: `.venv/bin/python output/independent/analyze_signal.py`。元音源は `assets/reference_audio.wav`。測定器はNumPy/SciPy/SoundFileを直接使用し、`p0`の特徴量・イベント検出コードを使用していない。原音源の変更・外部アップロードはない。

## 確認できた事実

### 1. 最初の35秒抜粋には終端の問題がある

初回planは原音の `[0, 771750)`、30fpsで1050フレームを選んだ。35秒終端の前100msのRMSは約−33.82 dBFS、後100msも約−35.80 dBFS。前後1秒はそれぞれ約−32.80 / −37.48 dBFSだった。この終端は独立測定の低エネルギー区間に含まれず、音が続いている。

これは「音楽的に誤ったフレーズ終止」という聴取結果ではない。しかし、音響上の休止があるという根拠はなく、活動度や区間内の変化点の個数だけで抜粋を採点するのは不十分である。原音を無加工で切り出す方針では、終端の残存音は映像側の正確な同期では解決できない。

### 2. アタックの位置と、どれを重要視するかは別問題

独立測定は1024サンプルHann窓、128サンプルhop、ゼロpaddingのスペクトル差分を使った。初回planの7アクセントと近傍の独立fluxピークの差は最大約29.02msだった。ただしこれは正解率ではない。複数のピークが密集しており、近傍の最寄りピークと一致することは容易になり得る。

実際、±250ms内で最も強いfluxピークを採ると、初回候補との差は最大約238.00msになる。この差は、独立測定器が正しくmuseが誤っている証拠でもない。どの音響事象を採用するかが手法や平滑化で変わるという、重要度の不確実性を示している。

独立測定器の時刻基準は、既知時刻に置いたimpulseと2msの立ち上がりを持つ減衰倍音信号で別途検証した。22,050 / 44,100 / 48,000Hz、2ゲイン、2信号種、各5アタックの12ケースでは、最大絶対誤差は約11.02ms。実演のペダル・多声部・レガートに対する精度ではない。

### 3. RMSだけでは落ちる情報が実際にある

1秒窓を比較すると、51〜52秒と149〜150秒のRMSは約−35.200 / −35.211 dBFSで差は0.011 dB。一方、スペクトルの正の立ち上がり量の合計は約2.27倍違った。RMSにほぼ同じ値を与える区間でも、音響的な変化の仕方は異なる。

この組は事後的に差の大きいものを選んだ例であり、映像の改善率を測った独立評価ではない。音域の違いもcentroidに反映されるため、音色や感情の識別結果とは解釈しない。

## 設計上の判断と未検証の仮説

- **採用する責務分離:** 原サンプル位置が時刻の基準。RMSの低速変化は光量等、立ち上がりは小さなアクセント、低速の音高構成・エネルギー変化は疎な構造候補に用いる。スコアを確率と呼ばない。
- **実装側へ渡す条件:** 候補検出の窓・padding・遅延を記録し、既知信号で時刻を検証。計画したframeへ描画する誤差とは別の項目にする。
- **抜粋選択の条件:** 30〜45秒内に収まる候補の両端について、元信号の短時間RMS、アタック近接、境界を支持する根拠を保存する。良い端点が見つからないことも記録し、自然な終止を保証したとしない。特定の秒数を正解としてハードコードしない。
- **未検証:** これらの組み合わせが人にとって自然な演出になるか。楽譜/MIDIが必要な境界の割合。未知の録音ゲイン・ノイズ・演奏様式への頑健性。

## museへ渡す作業の粒度

1. **端点評価の修正:** 入力と評価指標を指定し、旧候補の弱点を再現する。両端の根拠を保存して再選択し、親が元信号から再測定する。
2. **アクセント検出の校正:** 位置検出と重要度による間引きを分ける。まず合成信号の誤差と誤検出を試験し、その後に実演の密集箇所で候補の不確実性を表示する。
3. **描画到達の確認:** 音声の遅延・ドリフト、エンコード済みフレーム、無音・凍結・黒映像の負例を検査する。テストを通すために許容幅だけ広げない。

各作業は、親が仮説・入力・受け入れ条件を定め、museが実装・試験、親が独立測定して採否を決める。作品ごとの秒指定を人間が行う運用には戻さない。低頻度の世界観選択と公開判断、方式選定時の聴取比較は残る。
